# Weekly scheduler library research

## Ranked recommendation

### 1) `@event-calendar/core` — best overall fit
- Best match for a SvelteKit + Svelte 5 runes app that wants a ready-made Google-Calendar-like week grid.
- Native Svelte 5 component API.
- Has `timeGridWeek`, selection, drag, and resize.
- Open-source MIT.
- Lightweight claim in upstream docs: 35kb brotli.
- Known Svelte 5 note: upstream rewrote to runes and later fixed compatibility with Svelte `5.51.1+`.
- Recommended if you want the least integration friction.

Evidence:
- Svelte 5 component + `timeGridWeek`: https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/README.md#L232-L260
- Drag/resize (`editable`, `eventDrop`, `eventDurationEditable`, `eventResize`): https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/README.md#L883-L890 and https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/README.md#L1238-L1307 and https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/README.md#L1540-L1567
- Drag-to-create (`select` / `selectable`): https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/README.md#L1688-L1739
- MIT + 35kb claim: https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/README.md#L1-L10
- Svelte 5 runes rewrite: https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/CHANGELOG.md#L137-L142
- Svelte 5.51.1+ fix: https://github.com/vkurko/calendar/blob/ae95c9e1f27c6b036a693f10463ded25a85da696/CHANGELOG.md#L70-L72

- `@event-calendar/core`
- License: MIT
- npm unpacked size: ~543 KB

### 2) `@schedule-x/svelte` + premium plugins — best premium Svelte-native option
- Official Svelte wrapper exists.
- Good week/day UI and official Svelte docs.
- But drag/drop is premium, and upstream explicitly removed drag/resize from the OSS repo.
- Good option only if paid plugins are acceptable.

Evidence:
- Official Svelte component: https://github.com/schedule-x/schedule-x/blob/e1901983a26d92073a4ccb39e65495d431a594e2/README.md#L10-L17 and https://github.com/schedule-x/schedule-x/blob/e1901983a26d92073a4ccb39e65495d431a594e2/website/app/docs/frameworks/svelte/page.mdx#L13-L45
- Premium drag-and-drop plugin: https://github.com/schedule-x/schedule-x/blob/e1901983a26d92073a4ccb39e65495d431a594e2/website/app/docs/calendar/plugins/drag-and-drop/page.mdx#L6-L29
- OSS removal note: https://github.com/schedule-x/schedule-x/blob/e1901983a26d92073a4ccb39e65495d431a594e2/CHANGELOG.md#L89-L91
- Svelte 5 fix: https://github.com/schedule-x/schedule-x/blob/e1901983a26d92073a4ccb39e65495d431a594e2/CHANGELOG.md#L6-L14

npm:
- `@schedule-x/svelte`, `@schedule-x/calendar`
- Drag: `@sx-premium/drag-and-drop`
- Resize: premium too
- License: MIT for core, commercial for drag/resize
- npm unpacked sizes: calendar ~1019 KB, svelte wrapper ~10 KB, drag plugin package metadata ~235 KB

### 3) FullCalendar — best framework-agnostic fallback
- Very mature and battle-tested.
- Week time-grid is first-class.
- Drag/resize and date-range selection are documented and mature.
- No official Svelte connector, so you wrap the vanilla instance in a Svelte component.

Evidence:
- No Svelte connector listed, only React/Angular/Vue: https://github.com/fullcalendar/fullcalendar/blob/b5e3796ad73982eae08c1b4d17c957d803cd76dc/README.md#L12-L17
- Vanilla setup with `interaction` and `initialView: 'timeGridWeek'`: https://github.com/fullcalendar/fullcalendar/blob/b5e3796ad73982eae08c1b4d17c957d803cd76dc/README.md#L35-L59
- TimeGrid week/day docs: https://github.com/fullcalendar/fullcalendar-docs/blob/c823f87d71640f6571a2cfcc10362d553f90067f/_docs-v6/timegrid-view/timegrid-view.md#L33-L61

### 4) `@svar-ui/svelte-calendar` — promising Svelte-first option, but newer/commercially split
- Svelte/SvelteKit focused.
- Open-source week/day/month with move/resize/create.
- Timeline/resources are PRO-only, which matters if you later need richer scheduling.
- Looks good, but newer than Event Calendar and less proven.

Evidence:
- Svelte/SvelteKit focus + week support: https://github.com/svar-widgets/calendar/blob/5b7550a64862fd11a78f6cd46420f0c736d7e60c/README.md#L21-L23 and https://github.com/svar-widgets/calendar/blob/5b7550a64862fd11a78f6cd46420f0c736d7e60c/README.md#L31-L33 and https://github.com/svar-widgets/calendar/blob/5b7550a64862fd11a78f6cd46420f0c736d7e60c/README.md#L63-L80

- `@svar-ui/svelte-calendar`
- License: MIT
- npm unpacked size: ~127 KB

### 5) `@nomideusz/svelte-calendar` — most interesting new native Svelte 5 entrant
- Pure Svelte 5.
- Explicitly supports move, resize, and drag-to-create in planner views.
- Also exposes a headless API.
- Main downside is maturity/adoption risk: very new project.

Evidence:

## Headless drag options

### `@neodrag/svelte`
- Good low-level move primitive.
- Not a scheduler: no slot selection, no resize handles, no overlap layout, no recurring/time-grid logic.
- Best only if you already plan to build the calendar mechanics yourself.

Evidence:
- Svelte action, tiny, draggable-only framing: https://github.com/PuruVJ/neodrag/blob/4a02c43fb30b2f13df46e652ea89394f2d963fa7/packages/svelte/README.md#L13-L27 and https://github.com/PuruVJ/neodrag/blob/4a02c43fb30b2f13df46e652ea89394f2d963fa7/packages/svelte/README.md#L47-L82
- Svelte 5 peer support: https://github.com/PuruVJ/neodrag/blob/4a02c43fb30b2f13df46e652ea89394f2d963fa7/packages/svelte/package.json#L56-L58

### `svelte-dnd-action`
- Excellent for sortable zones, board UIs, and accessibility.
- Wrong abstraction for a week time-grid scheduler; it is item/zone oriented, not timeline oriented.
- It can help with all-day chips or side lists, but not the main calendar grid.

Evidence:
- Zone/list oriented API and accessibility focus: https://github.com/isaacHagoel/svelte-dnd-action/blob/e2264fe319882c2805108fe0fc962d5f96039a23/README.md#L19-L33 and https://github.com/isaacHagoel/svelte-dnd-action/blob/e2264fe319882c2805108fe0fc962d5f96039a23/README.md#L108-L144
- Svelte 5 event syntax note: https://github.com/isaacHagoel/svelte-dnd-action/blob/e2264fe319882c2805108fe0fc962d5f96039a23/README.md#L504-L507
- Package metadata still has outdated description, but peer deps allow Svelte 5 prereleases: https://github.com/isaacHagoel/svelte-dnd-action/blob/e2264fe319882c2805108fe0fc962d5f96039a23/package.json#L2-L4 and https://github.com/isaacHagoel/svelte-dnd-action/blob/e2264fe319882c2805108fe0fc962d5f96039a23/package.json#L54-L56

## Bottom line
- If you want open-source + ready-made + best Svelte 5 fit: use `@event-calendar/core`.
- If you want the most mature non-Svelte-specific fallback: use FullCalendar in a small Svelte wrapper.
- If you are okay paying for plugins: Schedule-X becomes more attractive.
- If you want a newer but very Svelte-native alternative with a future headless escape hatch: watch `@nomideusz/svelte-calendar`.
- Avoid starting from `neodrag` or `svelte-dnd-action` unless you actually want to build the scheduler mechanics yourself.
