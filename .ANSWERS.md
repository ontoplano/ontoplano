# Exceptional Day Planning — Design Proposal

## Problem

You want to plan a single day differently without altering the recurring weekly schedule, and still have it show up in history.

## Proposed Design

### Data model

Add an `exceptional_days` table:

```
exceptional_days
  id          integer PK autoincrement
  userId      text FK → user.id
  date        text (YYYY-MM-DD, unique per user)
  label       text (optional, e.g. "trip to SP", "sick day")
  createdAt   text DEFAULT CURRENT_TIMESTAMP
```

The existing `weekly_slots` table stays untouched. On an exceptional day, those slots are **suppressed** and replaced with `exceptional_slots`:

```
exceptional_slots
  id              integer PK autoincrement
  exceptionalDayId integer FK → exceptional_days.id
  startTime       text
  durationMinutes integer
  mode            text ('category' | 'activity')
  categoryId      integer FK (nullable)
  activityId      integer FK (nullable)
  label           text (nullable)
  active          integer (boolean, default 1)
```

Schema is identical to `weekly_slots` minus `weekday` — it's anchored to a date instead.

### Generation logic (week-generator.ts)

When generating task instances for a given date:

1. Check if `exceptional_days` has an entry for that date+user.
2. **If yes** → generate task instances from `exceptional_slots` for that day, ignoring `weekly_slots`.
3. **If no** → use `weekly_slots` as today.

The generated `task_instances` rows already carry `date`, so history works unchanged.

### UI

#### Planner page

Add a button in the planner week view: **"Override day"** (only on current or future days, not past).

Clicking it creates an `exceptional_day` for that date and opens an inline form (same UX as current slot form) scoped to that date. The day tab gets a small indicator (e.g. a dot or asterisk) showing it's overridden.

The override can be:
- **From scratch** — empty schedule, build manually.
- **Copy from regular** — pre-fill with the weekly_slots for that weekday, then edit.

A "Remove override" button restores the regular weekly plan.

#### History page

No changes needed. Task instances generated from exceptional slots appear in history the same way. The exceptional day label could show as a subtle annotation on the day header.

#### Dashboard

No changes needed. The day's task instances come from whichever source (regular or exceptional).

### Keyboard shortcuts

- `o` in planner → toggle exceptional day override for selected day
- Once in override mode, `n`/`e`/`d`/`D` work identically on exceptional slots

### Edge cases

- **Past exceptional days**: Read-only. The task instances were already generated.
- **Deleting an override**: Removes the exceptional_day + its slots. If task instances were already generated, they remain (they're independent records).
- **Week generation on override day**: The generator checks exceptional_days first, so no conflict.
- **Multiple overrides in one week**: Each date is independent. No limit.
